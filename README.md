# Технічне завдання

Добавити:

- поле name який є у всіх кінотеатрах.
- метод початку роботи (який є у всіх кінотеатрах), який виводить повідомлення в консоль "назва кінотеатру" + почав показ фільмів.
- додати метод виведення бенефітів який в кінотеатрi "Deluxe" виведе повідомлення "5Д, всі зали люксові", а в інших кінотеатрах виведе "низька ціна, великі зали"
- створити по одному об'єкту кожного кінотеатра, при створенні виводь повідомлення "Назва кінотеатру + створено.", не забудь про створення сутності кінотеатру як батька. У батька створення супроводжується повідомленням "Батько створений". Почати роботу кожим об'єктом, отримати бенефіти, закінчити роботу.
- метод закінчення роботи у кожного кінотеатра різний:
  - Cinema - пустий
  - Deluxe - має поле "в роботі" яке активізується при початку роботи і перевіряється при закінченні і виводить повідомлення : "Дякую за відвідування, заклад закривається."
  - Kinoman - має поле "кількість сеансів", повідомлення "Сьогодні було показано n сеансів, всім дякую."
  - Leipzig - повідомлення "Бай бай".
  - Multiplex - повідомлення "Сподіваюсь в наступний раз ви придбаєте більше попкону".
